# Databronnen

| Domein | Bron | Gebruik in v1 | Sleutel |
| --- | --- | --- | --- |
| Weer | Open-Meteo Forecast API | actuele temperatuur, wind en neerslagkans | nee |
| Luchtkwaliteit | Open-Meteo Air Quality API | PM10, PM2.5 en Europese AQI | nee |
| Transit | iRail / regionale feeds | roadmap | mogelijk afhankelijk van bron |
| Verkeer | TomTom of regionale open data | roadmap | meestal ja |
| Energie | gelicentieerde day-ahead-bron | roadmap | vaak ja |

Bewaar API-sleutels uitsluitend in lokale `.env`-bestanden of GitHub Secrets. Plaats nooit ruwe payloads met mogelijk gevoelige informatie in Git.
